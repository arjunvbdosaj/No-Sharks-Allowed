# No Sharks Allowed

Gym tracker for Arjun and Kanon.

## Files
index.html, config.js, sw.js, manifest.webmanifest and three PNG icons. Upload them all, at the top level of the repository, not inside a folder.

## Put it online with GitHub Pages
1. Create a public repository on github.com and upload every file with "uploading an existing file". Commit.
2. Settings, then Pages. Under "Build and deployment" pick "Deploy from a branch", branch `main`, folder `/ (root)`, and Save.
3. After a minute the site is at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Share data between two phones
Follow SETUP.md. Until you do, each device keeps its own data.

## Put it on a phone
- iPhone: open the address in Safari, tap Share, then "Add to Home Screen".
- Android: open it in Chrome, tap the menu, then "Install app" or "Add to Home screen".

## Updating later
Replace the files in the repository. If you change index.html, change `VERSION` in sw.js too (for example to `nsa-v3`).
